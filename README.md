# Job Trace

Personal tracking tools for job applications and housing searches. Built with Vite + React + TypeScript.

## Features

**Job Trace**
- Track job applications with status (投递中 / 面试中 / Offer / 已拒绝 / 已放弃)
- Sort by status priority
- Filter by year

**Housing Trace**
- Track housing listings with community, area, notes, and address
- Click address to open in Amap (高德地图)

## Quick Start

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```
